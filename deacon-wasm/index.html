deacon-wasm

Run Deacon locally to remove human DNA sequences from fasta/fastq, or perform abitrary search queries using a custom index.

Usage
  1. Press 'Download index' or wait for the cached panhuman-1 index to load, else drag & drop a local .idx/.pidx file.
  2. Drag & drop fasta/fastq files or a directory containing them. Illumina R1/R2 files are paired automatically.
  3. Adjust parameters if needed and press 'Filter'.
